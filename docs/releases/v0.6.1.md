# Readshot v0.6.1

## Summary

Fixes two macOS bugs:

- **Hold Shift = square selection** now actually works during region
  capture. The constraint was implemented but never reached the
  overlay because iced 0.14 doesn't pipe keyboard events into canvas
  widgets; a global listener now forwards Shift into the overlay.
- **Welcome window dismisses on Sequoia** once the user grants
  Screen & System Audio Recording. macOS 15 split this consent into
  two TCC keys; we previously only checked the legacy one and stayed
  stuck on the "grant permission" screen even though capture worked.
