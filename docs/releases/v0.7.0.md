# Readshot v0.7.0

## Highlights

* **Scrolling capture** — capture a region repeatedly as you scroll a
  page, then stitch the frames into one tall image. Live preview in a
  floating HUD, click-through region indicator on screen, exclusion
  of own windows from the capture so the HUD never bleeds in. Reach
  it from the overlay's ↕ Scroll button or the new tray "Scrolling
  Capture…" entry.
* **UX polish across the app** — discard-confirm in the editor,
  status toasts auto-dismiss, active-tool gets a real selection ring,
  two-step Clear All in history, keyboard nav works from the search
  box, Welcome's Denied state shows an amber warning, Settings gains
  a Recheck-permissions button and a Cancel-during-recording flow,
  pin window no longer destroys on double-click and its controls
  don't fight window drag.
