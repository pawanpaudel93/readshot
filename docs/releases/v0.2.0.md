# Readshot v0.2.0

## Summary

- Adds workflow polish for repetitive captures, direct OCR capture, pin windows, CLI text capture, and MCP capture retrieval.

## Changes

- Tray menu: Retake Last Region repeats the most recent overlay selection.
- Overlay toolbar: Copy Text copies recognised text without opening the editor.
- Pins: opacity and lock controls are stored per pin window.
- MCP: new `latest_capture` and `get_capture` tools retrieve saved history records directly.
- CLI: new `capture-text` command prints OCR text to stdout; `capture --last-region` is parsed and reports that it is GUI-session only.
