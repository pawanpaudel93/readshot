# Readshot v0.8.0

## Summary

- **Updates work again.** "Check for Updates…" could not load its update framework in self-signed builds (every release through 0.7.7); fixed.
- **Quit & Reopen after granting Screen Recording** now brings Readshot back even when macOS doesn't.
- **Editor:** undo/redo no longer hidden at the default width, zoom and frame controls moved below the image, multi-line text annotations, Shift to draw squares/circles and 45° lines, screen-sized selection handles, and a confirmation before closing with unsaved edits.
- **History:** readable timestamps ("Today 14:03"), search focused on open, delete confirmation, a list that refreshes as soon as a capture is saved, and paging for large histories.
- **Settings:** OCR engine and languages (by name), default export format, verbose logging, a hotkey recorder that accepts every supported key, and consistent styling.
- **Reliability:** Linux OCR no longer blocks, cross-process history locking, self-healing history index, and many smaller fixes.
