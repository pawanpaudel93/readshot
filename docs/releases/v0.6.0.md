# Readshot v0.6.0

## Summary

- Expanded Readshot's CLI automation with interactive region selection,
  clipboard output, delay timers, image format selection, cursor controls,
  and window-shadow options.
- Unified CLI interactive capture with the Readshot region selector so
  drag-and-release captures immediately without the app quick-action menu.
- Updated MCP, docs, and the website to describe the new capture options.
