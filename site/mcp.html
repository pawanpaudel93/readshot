MCP

readshot-mcp lets AI agent hosts capture screenshots, run OCR, and search local capture history through Model Context Protocol stdio.

Binary path

The one-line macOS installer creates a readshot-mcp symlink in ~/.local/bin. Use readshot-mcp in configs when the host inherits that PATH. Desktop MCP hosts often do not, so the absolute app-bundle path is the more reliable default.

OS Path
macOS /Applications/Readshot.app/Contents/MacOS/readshot-mcp
Source build ./target/release/readshot-mcp

Tools

Tool Use
list_displays Return capturable displays.
list_windows Return capturable app windows.
capture_region Capture a display region and return a PNG payload.
capture_window Capture a window, optionally with a window-relative region.
capture_text Capture a display region and return OCR text, laid out like the app’s Copy Text.
capture_region_and_text Return both PNG pixels and OCR text.
recent_captures Read recent captures from local history.
latest_capture Return the newest saved capture.
get_capture Return a saved capture by id.
search_captures Search local history metadata and OCR text.

When display is omitted, the primary display is used. When rect is omitted, the selected display or window is captured in full.

History results

The history tools read the same local archive as the app. Each result includes metadata, OCR text when available, the absolute PNG path, and redacted. A redacted capture never serves what its redactions hide.

Field Meaning
redacted true when the stored image is a redacted editor output. Its PNG is the redacted image.
ocr_text On a redacted capture, each word a redaction covers is masked with █. It is null by design when Readshot can’t prove the text is safe to serve: the capture was redacted where the OCR engine reports no word positions (Windows and Linux), the record’s list of redactions isn’t known to be complete, the record is a legacy one migrated on load, or a cropped, redacted capture hasn’t had its text recognized with word positions yet. In the last case the masked text is filled in once it has.
image_path null while a redaction is being written to disk. The unredacted image is already gone, so the record is text-only until the redacted image lands.

Arguments

rect is always an object in logical pixels: 

{ "x": 100, "y": 100, "width": 800, "height": 600 }

Region capture

Argument Notes
display Display id from list_displays. Defaults to the primary display.
rect Display-relative region. Defaults to the full display.
scale Optional HiDPI scale override. Defaults to the display scale.
hide_cursor Defaults to true. Set false to include the cursor when supported.

Window capture

Argument Notes
window Required. Window id from list_windows.
rect Window-relative region. Defaults to the full window.
ignore_shadows Defaults to false. Set true for tighter captures when supported.

OCR and history

Argument Notes
languages Optional BCP-47 language hints. Omit for automatic language detection.
language_correction Defaults to true where the platform OCR engine supports correction.
limit Used by history list/search tools. Minimum 1, maximum 100.
query Searches local history metadata and OCR text.

Limits, the same as the CLI’s: each rect value is at most 16,384, scale is at most 8, and one display or region capture is at most 100 million pixels after scaling. A request over a limit is refused with -32602.

Host config

Generate the standard JSON snippet from the CLI: 

readshot mcp-config
readshot mcp-config --command /Applications/Readshot.app/Contents/MacOS/readshot-mcp

Check the MCP binary directly: 

readshot-mcp --check

Terminal-launched hosts can usually use the short command: 

{
  "mcpServers": {
    "readshot": {
      "command": "readshot-mcp"
    }
  }
}

For desktop apps, prefer the absolute path below unless you know the app inherits ~/.local/bin from your shell.

Claude Desktop

{
  "mcpServers": {
    "readshot": {
      "command": "/Applications/Readshot.app/Contents/MacOS/readshot-mcp"
    }
  }
}

Cursor

{
  "mcpServers": {
    "readshot": {
      "command": "/Applications/Readshot.app/Contents/MacOS/readshot-mcp",
      "type": "stdio"
    }
  }
}

OpenAI Desktop or Codex CLI

[mcp_servers.readshot]
command = "/Applications/Readshot.app/Contents/MacOS/readshot-mcp"

Continue.dev

{
  "mcpServers": [
    {
      "name": "readshot",
      "command": "/Applications/Readshot.app/Contents/MacOS/readshot-mcp"
    }
  ]
}

Tool call examples

Capture a region and return both pixels and OCR text:

{
  "jsonrpc": "2.0",
  "id": 7,
  "method": "tools/call",
  "params": {
    "name": "capture_region_and_text",
    "arguments": {
      "rect": { "x": 100, "y": 100, "width": 800, "height": 600 }
    }
  }
}

Capture a window:

{
  "jsonrpc": "2.0",
  "id": 8,
  "method": "tools/call",
  "params": {
    "name": "capture_window",
    "arguments": {
      "window": "11474"
    }
  }
}

Capture text only:

{
  "jsonrpc": "2.0",
  "id": 9,
  "method": "tools/call",
  "params": {
    "name": "capture_text",
    "arguments": {
      "rect": { "x": 100, "y": 100, "width": 800, "height": 600 }
    }
  }
}

Search local history:

{
  "jsonrpc": "2.0",
  "id": 10,
  "method": "tools/call",
  "params": {
    "name": "search_captures",
    "arguments": {
      "query": "invoice",
      "limit": 10
    }
  }
}

Permissions

readshot-mcp does not prompt for Screen Recording itself. The host app that launches it, such as Claude Desktop or Cursor, needs Screen Recording permission in macOS System Settings.

A permission failure is a tool result with isError: true whose text says why (capture: screen capture permission denied), as the MCP spec asks for errors raised while a tool runs, so the agent can show it to the user. JSON-RPC errors are only for protocol problems such as an unknown tool or invalid arguments.

Errors

A tool that fails while running returns a normal result with isError: true. JSON-RPC errors are for protocol problems:

Code When
-32700 The line isn’t valid JSON, or it is longer than 8 MiB. The server answers and keeps reading.
-32600 The request is malformed: for example jsonrpc isn’t "2.0", method is missing, or id isn’t a string, number or null.
-32601 Unknown method, or tools/call names an unknown tool.
-32602 Invalid arguments, including an argument the tool doesn’t list or a value over a limit.

readshot-mcp --check exits with code 70 when no tools are advertised or the history folder isn’t writable. Any argument other than --check or --help exits with code 64.

Verify

Set the binary path and ask the server for its advertised tools.

READSHOT_MCP=/Applications/Readshot.app/Contents/MacOS/readshot-mcp
"$READSHOT_MCP" --check

printf '{"jsonrpc":"2.0","id":1,"method":"tools/list"}\n' \
  | "$READSHOT_MCP" \
  | python3 -m json.tool

List capturable windows:

printf '{"jsonrpc":"2.0","id":2,"method":"tools/call","params":{"name":"list_windows","arguments":{}}}\n' \
  | "$READSHOT_MCP" \
  | python3 -m json.tool

Troubleshooting

Symptom Likely cause
command not found The host is using the wrong binary path.
isError: true, “screen capture permission denied” The host app lacks Screen Recording permission.
Empty display or window list No capturable surface was available or permission was denied.
A capture tool returns empty OCR text The selected region is too small or contains no rendered text.
A history result has ocr_text: null It’s a redacted capture whose text Readshot can’t prove is safe to serve. This is by design; see History results.
A history result has image_path: null A redaction is still being written to disk. Read the capture again once it lands.
