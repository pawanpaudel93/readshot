# Readshot v0.8.1

## Summary

- **Screen Recording after updates:** if macOS still holds a grant from an
  older, differently signed version, "Allow Screen Recording" now clears it
  and asks again, so switching Readshot on works. There's also a
  **Reset Permission** button when access is blocked.
- **No more stuck permission alert:** the macOS "would like to record this
  computer's screen" alert is no longer re-raised twice a second.
- **Built-in uninstall:** Settings → Uninstall Readshot…,
  `readshot uninstall` (`-n` to preview, `-y` to skip the prompt,
  `--purge` to also delete history, preferences, and caches), or
  `install.sh --uninstall`.
- **Installer:** no more `mount_dir: unbound variable` at the end of
  `curl … | bash`, and no leftover temp folder.
- Release builds are now checked against the pinned signing certificate,
  so future updates keep your permissions.

**Updating from 0.7.7 or earlier (0.3.x):** those builds used a different
signing certificate, so macOS asks for Screen Recording once more after
updating. Click **Allow Screen Recording** and switch Readshot on.
