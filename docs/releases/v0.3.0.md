# Readshot v0.3.0

## Summary

- Adds CLI and MCP window capture, including window-relative region crops, and tightens capture workflow labels and docs.

## Changes

- CLI: new `list-windows` command lists capturable app windows.
- CLI: new `capture-window` command captures a full app window.
- CLI: `capture-window --rect x,y,width,height` crops relative to the selected window's top-left.
- MCP: new `list_windows` and `capture_window` tools expose window capture to AI-agent hosts.
- MCP: `capture_window.rect` supports window-relative region capture.
- Editor: zoom controls now distinguish Fit, 100%, and custom zoom states more clearly.
- Tray/menu: removed confusing placeholder capture actions and disabled Retake Last Region until a region exists.
- Retake Last Region: uses the most recent selected region and display deterministically.
- Docs: clarified text-capture surfaces, public platform support, MCP smoke tests, and incomplete future surfaces.
