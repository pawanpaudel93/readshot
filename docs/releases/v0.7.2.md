# Readshot v0.7.2

## Summary

- Editor: selected annotations can now be moved, deleted, resized, and edited without redrawing them.
- Sharing: Copy Framed creates a cleaner share-ready image with margin and shadow.
- Capture flow: region captures hand off to the editor faster, and editor / utility windows open on the monitor where the action started.
- Scrolling capture: duplicate frames are rejected so stitched captures contain fewer repeated strips.
